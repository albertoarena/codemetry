Anthropic's Claude models are known for thoughtful, nuanced responses and strong reasoning capabilities.

## Setup

<Steps>

1. **Get an API Key**

   Visit [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) to create an API key.

2. **Set Environment Variable**

   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   ```

   Or add to your `.env` file:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. **Configure Codemetry**

   ```php
   // config/codemetry.php
   'ai' => [
       'enabled' => true,
       'engine' => 'anthropic',
       'model' => null,  // Uses claude-sonnet-5-5 by default
   ],
   ```

4. **Run Analysis**

   ```bash
   php artisan codemetry:analyze --days=7 --ai=1 --ai-engine=anthropic
   ```

</Steps>

## Available Models

| Model | Default | Cost | Quality | Speed |
|-------|---------|------|---------|-------|
| `claude-sonnet-5-5` | ✓ | Medium | Excellent | Medium |
| `claude-haiku-5-5` |  | Low | Good | Fast |
| `claude-opus-5-5` |  | High | Best | Slower |

Anthropic retires models regularly. If a model on this page stops working, check the provider's model list and set a current one.

### Choosing a Model

**For routine analysis:** Use `claude-sonnet-5-5` (default)
- Strong reasoning about metric patterns at a moderate price

**Alternative:** Use `claude-haiku-5-5`
- Fastest and cheapest; enough for routine daily or weekly runs

**For critical analyses:** Use `claude-opus-5-5`
- Anthropic's most capable model; use it for occasional deep investigations

There is no `--ai-model` flag. To override the model for a single run, set `CODEMETRY_AI_MODEL`:

```bash
CODEMETRY_AI_MODEL=claude-haiku-5-5 php artisan codemetry:analyze --days=7 --ai=1 --ai-engine=anthropic
```

Or in configuration:

```php
'ai' => [
    'engine' => 'anthropic',
    'model' => 'claude-haiku-5-5',
],
```

## API Key Options

Codemetry checks for API keys in this order:

1. `CODEMETRY_AI_API_KEY` — Unified key for any engine
2. `ANTHROPIC_API_KEY` — Anthropic-specific key

```bash
# Option 1: Unified
export CODEMETRY_AI_API_KEY=sk-ant-...

# Option 2: Engine-specific
export ANTHROPIC_API_KEY=sk-ant-...
```

## Cost Management

Anthropic charges per token. Codemetry sends minimal data:
- ~500-1000 input tokens per day analyzed
- ~200-500 output tokens per summary

Prices change often, so check [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing) for current per-token rates.

<Aside type="tip">
  For frequent routine runs, `claude-haiku-5-5` costs noticeably less than the Sonnet default and is usually enough for metric explanations.
</Aside>

## Troubleshooting

### "Invalid API key"

**Cause:** API key is incorrect or expired.

**Solution:**
- Verify key at [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
- Check for typos or extra whitespace
- Ensure key is active

### "Rate limit exceeded"

**Cause:** Too many requests or exceeded tier limits.

**Solution:**
- Wait and retry (usually 1-5 minutes)
- Check usage in Anthropic console
- Consider requesting higher limits

### "Overloaded"

**Cause:** Anthropic API is experiencing high load.

**Solution:**
- Retry after a few seconds
- This is usually temporary

### "Model not available"

**Cause:** Model name incorrect or not available in your region.

**Solution:**
- Check model name spelling
- Use a different model variant
- Verify API access includes the requested model

<Aside type="note">
  Anthropic occasionally updates model names. If a model stops working, check the [Anthropic documentation](https://docs.anthropic.com/en/docs/about-claude/models) for current model names.
</Aside>
